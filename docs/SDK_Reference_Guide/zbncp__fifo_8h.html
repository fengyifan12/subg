#define FIFO_MAX_SIZE_ALLOWED   (1ul << ((sizeof(zbncp_fifo_size_t) * 8u) - 1u))

Constant describing the maximum possible count of the FIFO entries.

This implementation does not wrap the head and the tail indices on enqueue/dequeue operations but instead it continuously increments them and do wrapping only on head/tail accessing. This enables us to always know the current count of stored elements by subtracting the head index from the tail index. This operation works correctly even in the case of integer overflow (i.e. when the actual value of the tail index is larger than the value of the head index) but only if the difference is less than the half of the maximum value that can be stores in the index type.

NB! To get the half of the maximum value and avoid an overflow we need to caclulate it using the formula 2 ^ (SIZE-OF-TYPE-IN-BITS - 1) instead of (2 ^ SIZE-OF-TYPE-IN-BITS) / 2.
