zb_uint8_t zb_apsme_transport_key_req_t::addr_mode

The type of destination address supplied by the DstAddr parameter - see address_modes. This field is non-standard: according to table 4.11 dest_address can be 64-bit only. But, according to 4.6.3.4.1 Trust Center Operation, TC must issue APSME-TRANSPORT-KEY.request with broadcast address - means, need 16-bit address here!
