Detailed Description

Generic implementation of a variable length bitfield, implemented as an array. Bitfields should be declared as an array of uint32_t with length BITFIELD_BLOCK_COUNT(BITS).

Example: A 48 bit bitfield:

uint32_t bitfield[BITFIELD_BLOCK_COUNT(48)];
