Detailed Description

Chip definition file. Define software build code based on chip type and chip version. Please change the definition of CHIP_TYPE and CHIP_VERSION to match real product IC. User can redefine CHIP_TYPE and CHIP_VERSION by one of two options:

  1. Select Target in Keil IDE will change CHIP_TYPE and CHIP_VERSION definitions in the Preprocessor Symbols field.
  2. User can define CHIP_TYPE and CHIP_VERSION in this file if they are not defined in the Preprocessor Symbols field. User can use the CHIP_MODEL definition which is defined by CHIP_TYPE and CHIP_VERSION.
