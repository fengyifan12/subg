Detailed Description

This file defines the top-level functions for the OpenThread BLE Secure implementation.

Note
The functions in this module require the build-time feature OPENTHREAD_CONFIG_BLE_TCAT_ENABLE=1.
To enable cipher suite DTLS_PSK_WITH_AES_128_CCM_8, MBEDTLS_KEY_EXCHANGE_PSK_ENABLED must be enabled in mbedtls-config.h To enable cipher suite DTLS_ECDHE_ECDSA_WITH_AES_128_CCM_8, MBEDTLS_KEY_EXCHANGE_ECDHE_ECDSA_ENABLED must be enabled in mbedtls-config.h.
