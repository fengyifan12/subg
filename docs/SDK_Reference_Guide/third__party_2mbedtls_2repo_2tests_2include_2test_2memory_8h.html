◆ MBEDTLS_TEST_MEMORY_POISON

#define MBEDTLS_TEST_MEMORY_POISON (   ptr,
  size 
)    ((void) (ptr), (void) (size))

Poison a memory area so that any attempt to read or write from it will cause a runtime failure.

Depending on the implementation, this may poison a few bytes beyond the indicated region, but will never poison a separate object on the heap or a separate object with more than the alignment of a long long.

The behavior is undefined if any part of the memory area is invalid.

This is a no-op in builds without a poisoning method. See #MBEDTLS_TEST_MEMORY_CAN_POISON.

Parameters
bufPointer to the beginning of the memory area to poison.
sizeSize of the memory area in bytes.

#define MBEDTLS_TEST_MEMORY_UNPOISON (   ptr,
  size 
)    ((void) (ptr), (void) (size))

Undo the effect of MBEDTLS_TEST_MEMORY_POISON.

The behavior is undefined if any part of the memory area is invalid, or if the memory area contains a mixture of poisoned and unpoisoned parts.

This is a no-op in builds without a poisoning method. See #MBEDTLS_TEST_MEMORY_CAN_POISON.

Parameters
bufPointer to the beginning of the memory area to unpoison.
sizeSize of the memory area in bytes.
