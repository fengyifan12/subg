samkumar: The FreeBSD Operating System uses its callout subsystem to implement TCP timers. I've removed the relevant definitions/declarations below, since TCPlp relies on the host system to implement TCP timers. To save memory, I've removed some configurability (e.g., per-TCB keepalive parameters) and global statistics (e.g. tcp_keepcnt).
