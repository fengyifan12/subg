Helper functions for tests that manipulate ASN.1 data. Skip past an INTEGER in an ASN.1 buffer.

Mark the current test case as failed in any of the following conditions:

  • The buffer does not start with an ASN.1 INTEGER.
  • The integer's size or parity does not match the constraints expressed through min_bits, max_bits and must_be_odd.
Parameters
pUpon entry, *p points to the first byte of the buffer to parse. On successful return, *p points to the first byte after the parsed INTEGER. On failure, *p is unspecified.
endThe end of the ASN.1 buffer.
min_bitsFail the test case if the integer does not have at least this many significant bits.
max_bitsFail the test case if the integer has more than this many significant bits.
must_be_oddFail the test case if the integer is even.
Returns
0 if the test failed, otherwise 1.
