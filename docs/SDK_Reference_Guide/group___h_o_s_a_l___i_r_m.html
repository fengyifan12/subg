◆ hosal_irm_open()

uint32_t hosal_irm_open ( hosal_irm_mode_t *  irm_cfg)

Set IRM initialize.

Parameters
[in]irm_cfgirm config
Returns
STATUS_SUCCESS

Call this function to initail IRM, the whole IRM driver is interrupt-driven, all IRM response are processing in user "irm_cb_func" callback function. Please Notice the the function "irm_cb_func" is in ISR context, so finish the task ASAP. You can NOT block the function!
