Bind destination address mode

The addressing mode for the destination address used in zb_zdo_binding_table_record_s, zb_zdo_bind_req_param_s, zb_zdo_bind_req_head_s command. This field can take one of the non-reserved values from the list of defines below (bind_dst_addr_mode). Values 0x00, 0x02, 0x04-0xff are reserved.

ZB Spec, subclause 2.4.3.2.2.

void zb_zdo_disable_network_mgmt_channel_update ( zb_bool_t  disable)

Disable channel update (affected for coordinator role only)

The current ZB channel can be changed inside the stack for internal reasons or as a result of processing Mgmt NWK Update Notify commands. Call this function to prevent such channel changes if it is not allowable for the application.

Parameters
disable- specify if channel update is disabled (enabled by default)
