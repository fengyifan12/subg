 Function for sending data over UART. If an event handler was provided in uart_init() call, this function returns immediately and the handler is called when the transfer is done. Otherwise, the transfer is performed in blocking mode, i.e. this function returns when the transfer is finished. During the operation it is not allowed to call this function or any other data transfer function again in non-blocking mode. Also the data buffers must stay allocated and the contents of data must not be modified.
