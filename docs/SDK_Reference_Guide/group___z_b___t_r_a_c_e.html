Start net trace, optionally put trace to net.

Must be called after network initialization is done.

Parameters

put2net_atboot_func- callback to be used to write trace to net just after boot, when applications, like gw, are not running yet
nettrace_startup_done- callback to be called when startup process is completed and all atboot trace messages are processed
