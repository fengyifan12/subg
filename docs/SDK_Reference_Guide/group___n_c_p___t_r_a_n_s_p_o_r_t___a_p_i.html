◆ spi_callback_t

typedef void(* spi_callback_t) (uint8_t param)

Type of callback called by Linux SPI when it completed initialization or sendign data.

After a user calls linux_spi_init(), then one receives notification callback on initialization completion.

After a user calls linux_spi_send_data() to pass a buffer to the transport, then one receives notification callback on sending completion with a status of the operation.

Parameters
param- parameter to the callback unused for initialization completion callback status of the operation for sending completion calback

◆ spi_recv_data_cb_t

typedef void(* spi_recv_data_cb_t) (uint8_t *buf, uint16_t len)

Type of callback called by Linux SPI when it received some data.

A user first calls linux_spi_recv_data() to pass a buffer to the transport, then one receives notification callback on receving completion with the recevied data buffer pointer and with recevied byte count.

Parameters
buf- pointer to data received
len- length actually received
