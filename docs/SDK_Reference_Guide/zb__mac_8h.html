Builds MLME-ASSOCIATE request. This request allows a device to request an association with a coordinator.

Parameters
buf- pointer to zb_buf_t.
_channel_page- the channel page on which to attempt association.
_logical_channel- selected from the available logical channels supported by the PHY.
coord_PAN_id- the identifier of the PAN with which to associate.
addr_mode- ZB_ADDR_16BIT_DEV_OR_BROADCAST or ZB_ADDR_64BIT_DEV. See address_modes.
p_address- pointer of the address of the coordinator with which to associate, Suppose 64-bit address mode.
_capability- zb_mac_capability_info_t struct. Specifies the operational capabilities of the associating device.
