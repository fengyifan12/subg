354 /*
355  * Specific hash functions.
356  *
357  * Rules for contexts:
358  * -- No interior pointer.
359  * -- No pointer to external dynamically allocated resources.
360  * -- First field is called 'vtable' and is a pointer to a
361  * const-qualified br_hash_class instance (pointer is set by init()).
362  * -- SHA-224 and SHA-256 contexts are identical.
363  * -- SHA-384 and SHA-512 contexts are identical.
364  *
365  * Thus, contexts can be moved and cloned to capture the hash function
366  * current state; and there is no need for any explicit "release" function.
367  */
