Detailed Description

Record decryption engine class, for CBC mode.

This class type extends the decryption engine class with an initialisation method that receives the parameters needed for CBC processing: block cipher implementation, block cipher key, HMAC parameters (hash function, key, MAC length), and IV. If the IV is NULL, then a per-record IV will be used (TLS 1.1+).
