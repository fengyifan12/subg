◆ sm4_acquire()

uint32_t sm4_acquire ( void  )

This function acquire SM4 crypto engine.

Returns
STATUS_SUCCESS

This function only used in multi-tasking OS. Only one SM4 encryption/decryption request can be serviced at any time. To avoid more than two tasks request the hardware engine resource at the same time, there should be a semaphore protect to protect the hardware request run one by one. In single thread environment (FSM), sm4_acquire() function is always return STATUS_SUCCESS Notice: semaphore protect function depends on OS implemented.

uint32_t sm4_release ( void  )

This function release SM4 crypto engine.

Returns
STATUS_SUCCESS STATUS_ERROR: Hardware Engine is not in SM4 mode

This function only used in multi-tasking OS. If the task acquired the hardware engine before, it should call this function to release the resource. In single thread environment (FSM), aes_release function always return STATUS_SUCCESS Notice: semaphore protect function depends on OS implemented.
