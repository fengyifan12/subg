Detailed Description

qspi_transfer_mode_t Structure for the spi controller mode setting. SPI_BIT_ORDER: for select MSB or LSB shifted out first. SPI_CPHA/SPI_CPOL: for SPI data sample timing and CLK active low or active high. SPI_CS_POL: for select chip active low or active high. SPI_MASTER: for select the controller to be master or slave. SPI_CS: for the controller SPI0, it can support 4 spi slave devices. For slave device, this setting is the pin connected to SPI host. SPI_CLK: the master output clk frequency. For slave device, this setting will be ignored.

qspi_transfer_mode_t Structure for the spi controller mode setting. SPI_BIT_ORDER: for select MSB or LSB shifted out first. SPI_CPHA/SPI_CPOL: for SPI data sample timing and CLK active low or active high. SPI_CS_POL: for select chip active low or active high. SPI_MASTER: for select the controller to be master or slave. SPI_CS: for the controller SPI0, it can support 4 spi slave devices. For slave device, this setting is the pin connected to SPI host. PRE_DELAY_ENABLE: Enable pre-delay SCLK, this delay SCLK will be inserted when CS is active the dealy pre_delay SCLK. If system does not require this option, please set this option 0 to disable pre_delay. For slave device, this setting will be ignored. INTER_DELAY_ENABLE: Enable inter-transfer dealy SCLK, this delay SCLK will be inserted between two continuous SPI transfer. If system does not require this option, please set this option 0 to disable inter_delay. For slave device, this setting will be ignored. POST_DELAY_ENABLE: Enable post-delay SCLK, this delay SCLK will be inserted before CS change from active to non-active. If system does not require this option, please set this option 0 to disable inter_delay. For slave device, this setting will be ignored. PRE_DELAY_COUNT: If PRE_DELAY_ENABLE is enable (1), number of "PRE_DELAY_COUNT+1" spi SCLK will be inserted between CS becomes active and sending the first SPI data. Maximum delay counter is 256 SPI SCLK. INTER_DELAY_COUNT: If INTER_DELAY_ENABLE is enable (1), number of "INTER_DELAY_COUNT+1" spi SCLK will be inserted between two continuous SPI transfer. POSE_DELAY_COUNT: If POST_DELAY_ENABLE is enable (1), number of "POST_DELAY_ENABLE+1" spi SCLK will be inserted before CS becomes inactive to stop transfer. SPI_CLK: the master output clk frequency. For slave device, this setting will be ignored.
