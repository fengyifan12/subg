NCP Low level protocol library memory requirements

NCP LL library memory requirements

RAM

RAM consumption can be tuned by changing following constants:

  • ZBNCP_BIG_BUF_SIZE - maximum size of fragmented packet. Now 1600b
  • ZBNCP_LL_PKT_SIZE_MAX - maximum size of fragment to be transmitted by transport (SPI etc). Now 256b

RAM used by NCP LL library (without i/o layer):

  • 2 buffers (rx and tx) per 1 fragment - 2 * 256 = 512
  • big packet buffer for rx packet reassembly = 1600b
  • big packet buffer for tx packet divide = 2 * 1600b = 3200b
  • extra 732 bytes of internal data structuers

Total RAM usage: 6044b.

Flash

Code size depends on architecture and compiler.

Code used by NCP LL library (without i/o level) at TI CC1352 Cortex MCU compiled by ARM ccs compiler is 3342 bytes.
