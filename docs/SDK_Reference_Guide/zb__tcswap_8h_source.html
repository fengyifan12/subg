40 /*
41 #### Backup DB format
42 
43 Data to be backed up is divided into sections.
44 
45 TC info section:
46 
47 - flags:
48  - Installcodes backed up
49  - binding backed up
50 - ext panid (8b)
51 - IEEE address of TC (8b)
52 
53 Devices info. Used to backup device keys as well as its installcodes.
54 
55 - # of devices
56 - devices info []
57  - device IEEE
58  - contents bitmap (key/installcode/passphrase)
59  - key attributes :2 zb_secur_key_attributes_t
60  - security level :3 (initial join authentication + key negotiation method)
61  - hashed device key [8] (opt)
62  - prev hashed device key [8] (opt)
63  - Installcode [8] (opt)
64  - passphrase [8] (opt)
65 
66 Binding info section (optional - implement later):
67 
68 - # if bindings[]
69 - binding table []
70  - uint16 src profileid
71  - uint8 src ep
72  - uint8 dst_type
73  - IEEE dest ieee / uint16 group id
74 
75 Binding info section is not required for SE.
76  */
