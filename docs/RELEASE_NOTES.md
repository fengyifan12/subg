## 🔖 Changelog  
- Update Rafael Extension , add enviroment setup 
- Added Cortex-M33 MCU and RF driver compatibility  
- Integrated peripheral drivers (UART, SPI, I2C, PWM, SADC)  


## 📡 Protocol Support  
- Bluetooth Low Energy (BLE)  
- Zigbee  
- Mesh Networking  
- Sub-G Wireless Communication
