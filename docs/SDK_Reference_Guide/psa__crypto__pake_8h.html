Provide input for a step of a password-authenticated key exchange.

The signature of this function is that of a PSA driver pake_input entry point. This function behaves as a pake_input entry point as defined in the PSA driver interface specification for transparent drivers.
The core checks that input_length is smaller than PSA_PAKE_INPUT_MAX_SIZE.
