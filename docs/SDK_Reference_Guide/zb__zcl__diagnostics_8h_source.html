578 /* ACHTUNG! ATTENTION!
579  * If you need to add a counter, do the following steps:
580  * 1) add a macro to declare an attribute like it's done above:
581  * ZB_SET_ATTR_DESCR_WITH_*attr_id*(data_ptr)
582  * 2) declare the attribute in the attributes list:
583  * ZB_ZCL_DECLARE_DIAGNOSTICS_ATTRIB_LIST
584  * 3) implement your counter at:
585  * 3.1) ZDO
586  * - zb_zdo_globals.h -> zdo_diagnostics_info_t
587  * - zdo_diagnostics.h -> zdo_diagnostics_counter_id_t
588  * - zdo_diagnostics.c -> zdo_diagnostics_inc()
589  * - increment your counter in code using the ZDO_DIAGNOSTICS_INC() macro;
590  * OR
591  * 3.2) MAC
592  * - zb_mac.h -> zb_mac_diagnostic_info_t
593  * - mac_zcl_diagnostic.c -> implement a function to increment the counter;
594  * - mac_internal.h -> add macros to use the incrementing function;
595  * - increment your counter in code using the macro;
596  * 4) add copying the counter value to
597  * zcl_diagnostics_commands.c -> zb_zcl_diagnostics_get_attr_value_by_id()
598  *
599  * Important note:
600  * We have asynchronous reading the Diagnostics attributes:
601  * in the zb_zcl_read_attr_handler() we call zdo_diagnostics_get_stats()
602  * that will copy all counters to the same bufer from the first byte.
603  * What the problem? We have the following buffer stucture:
604  * a) buffer begin (from zero byte! not from zb_buf_begin()) - will contain all counters;
605  * b) buffer middle (from zb_buf_begin()) - contains one or more zb_zcl_read_attr_req_t;
606  * c) buffer end (can be get with ZB_BUF_GET_PARAM()) - contains zb_zcl_parsed_hdr_t.
607  * As you see, we can place all counters only from buffer begin (a).
608  * It's possible to get a situation when we don't have enough space,
609  * and you will catch assert in the zdo_diagnostics_get_mac_stats_cb() function.
610  * In this case it's necessary to move data from buffer middle to the right a bit.
611  */
