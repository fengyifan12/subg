◆ otMacFrameGenerateEnhAckProbingIe()

uint8_t otMacFrameGenerateEnhAckProbingIe ( uint8_t *  aDest,
const uint8_t *  aIeData,
uint8_t  aIeDataLength 
)

Write Enh-ACK Probing IE (Vendor IE with THREAD OUI) to a buffer.

aIeData could be NULL. If aIeData is NULL, this method generates the IE with the data unset. This allows users to generate the pattern first and update value later. (For example, using otMacFrameSetEnhAckProbingIe)

Parameters
[out]aDestA pointer to the output buffer.
[in]aIeDataA pointer to the Link Metrics data.
[in]aIeDataLengthThe length of Link Metrics data value. Should be 1 or 2. (Per spec 4.11.3.4.4.6)
Returns
The total count of bytes (total length of the Vendor IE) written to the buffer.

◆ otMacFrameProcessTxSfd()

otError otMacFrameProcessTxSfd ( otRadioFrame *  aFrame,
uint64_t  aRadioTime,
otRadioContext *  aRadioContext 
)

Perform processing of SFD callback from ISR.

This function may do multiple tasks as follows.

  • CSL IE will be populated (if present)
  • Time IE will be populated (if present)
  • Tx timestamp will be populated
  • Tx security will be performed (including assignment of security frame counter and key id if not assigned)
Parameters
[in,out]aFrameThe target frame. MUST NOT be NULL.
[in]aRadioTimeThe radio time when the SFD was at the antenna.
[in,out]aRadioContextThe radio context accessible in ISR.
Returns
the error processing the callback. The caller should abort transmission on failures.
