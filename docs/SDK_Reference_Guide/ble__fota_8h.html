◆ ble_fota_cmd()

void ble_fota_cmd ( uint8_t  host_id,
uint8_t  length,
uint8_t *  p_data 
)

Ble FOTA command processing

Parameters
[in]host_id: thid links's host id.
[in]length: command length.
[in]p_data: command payload.
Note
First byte of command payload contains command ID and each command ID may contain different information behind. OTA_CMD_QUERY : Get device current system information.
OTA_CMD_START : Start FW upgrade, this command contains new FW length and CRC.
OTA_CMD_ERASE : Terminated the connection and erasing legacy FW and informations.
OTA_CMD_APPLY : Apply the new FW if receiving FW length and CRC matched with OTA_CMD_START.
Returns
none
