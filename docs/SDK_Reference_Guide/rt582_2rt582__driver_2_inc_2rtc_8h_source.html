33  * RTC_MODE_EVERY_SEC_INTERRUPT mode will trigger rtc "second interrupt" for
34  * every "second" if RTC_MODE_EN_SEC_INTERRUPT mode set.
35  * RTC_MODE_MATCH_SEC_INTERRUPT mode will only trigger rtc "second interrupt"
36  * "current second" = "alarm second" once per minute, if RTC_MODE_EN_SEC_INTERRUPT
37  * mode set.
38  * RTC_MODE_SECOND_EVENT_INTERRUPT will generate "event interupt" every SS matched,
39  * if RTC_MODE_EVENT_INTERRUPT should be enable.
40  * RTC_MODE_EVERY_MIN_INTERRUPT mode will trigger rtc "min interrupt" for every
41  * "minute" if RTC_MODE_EN_MIN_INTERRUPT mode set.
42  * RTC_MODE_MATCH_MIN_INTERRUPT mode will only trigger rtc "minute interrupt"
43  * "current minute" = "alarm minute" once per hour, if RTC_MODE_EN_MIN_INTERRUPT
44  * mode set.
45  * RTC_MODE_MINUTE_EVENT_INTERRUPT will generate "event interupt" for MM:SS matched.
46  * (RTC_MODE_SECOND_EVENT_INTERRUPT should NOT set for this option. And
47  * RTC_MODE_EVENT_INTERRUPT should be enable.)
48  * RTC_MODE_EVERY_HOUR_INTERRUPT mode will trigger rtc "hour interrupt" for every
49  * "HOUR" if RTC_MODE_EN_HOUR_INTERRUPT mode set.
50  * RTC_MODE_MATCH_HOUR_INTERRUPT mode will only trigger rtc "hour interrupt"
51  * "current hour" = "alarm hour" once per day, if RTC_MODE_EN_HOUR_INTERRUPT mode set.
52  * RTC_MODE_HOUR_EVENT_INTERRUPT will generate "event interupt"for HH:MM:SS matched.
53  * (RTC_MODE_MIN_EVENT_INTERRUPT and RTC_MODE_SEC_EVENT_INTERRUPT should
54  * NOT set for this option. And RTC_MODE_EVENT_INTERRUPT should be enable.)
55  * RTC_MODE_EVERY_DAY_INTERRUPT mode will trigger rtc "day interrupt" for every
56  * "DAY" if RTC_MODE_EN_DAY_INTERRUPT mode set.
57  * RTC_MODE_MATCH_DAY_INTERRUPT mode will only trigger rtc "day interrupt"
58  * "current day" = "alarm day" once per month, if RTC_MODE_EN_DAY_INTERRUPT mode set.
59  * RTC_MODE_DAY_EVENT_INTERRUPT will generate "event interupt" for DAY HH:MM:SS matched
60  * (RTC_MODE_HOUR_EVENT_INTERRUPT, RTC_MODE_MIN_EVENT_INTERRUPT and
61  * RTC_MODE_SEC_EVENT_INTERRUPT should NOT set for this option.
62  * And RTC_MODE_EVENT_INTERRUPT should be enable.)
63  * RTC_MODE_EVERY_MONTH_INTERRUPT mode will trigger rtc "month interrupt" for every
64  * "month" if RTC_MODE_EN_MONTH_INTERRUPT mode set.
65  * RTC_MODE_MATCH_MONTH_INTERRUPT mode will only trigger rtc "month interrupt"
66  * "current month" = "alarm month" once per year, if RTC_MODE_EN_MONTH_INTERRUPT mode set.
67  * RTC_MODE_MONTH_EVENT_INTERRUPT will generate "event interupt" for MON:DAY HH:MM:SS matched.
68  * (RTC_MODE_DAY_EVENT_INTERRUPT, RTC_MODE_HOUR_EVENT_INTERRUPT,
