Detailed Description

When Mbed TLS is built with the MBEDTLS_PSA_CRYPTO_SPM option enabled, this header is included by all .c files in Mbed TLS that use PSA Crypto function names. This avoids duplication of symbols between TF-M and Mbed TLS.

Note
This file should be included before including any PSA Crypto headers from Mbed TLS.
