Detailed Description

HA OTA Upgrade client device.

OTA Upgrade client device has 2 clusters:

  • ZB_ZCL_BASIC
  • ZB_ZCL_OTA_UPGRADE_CLIENT

Sample use OTA Upgrade client device

Example
Delcaration client clusters
Register client device list
Delcaration server clusters
Register server device list

See ha/ota_upgrade test
