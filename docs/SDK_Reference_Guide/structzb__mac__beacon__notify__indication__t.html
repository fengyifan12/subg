Detailed Description

Defines MLME-BEACON-NOTIFY.indication.

Parameters
bsn- the beacon sequence number (or enhanced beacon sequence number).
pan_descriptor- the Pan Descriptor for the received.
pend_addr_spec- the beacon pending address specification.
addr_list- the list of addresses of the devices for which the beacon source has data.
beacon_type- indicates whether a beacon or an enhanced beacon was received.
sdu_length- the number of octets contained in the beacon payload of the beacon frame received by the MAC sublayer.
total_hie_size- the total size of header IEs stored in sdu, in bytes.
total_pie_size- the total size of payload IEs stored in sdu, in bytes.
rssi- custom field; used to execute Beacons Survey procedure in WWAH and r23
sdu- depending on beacon_type:
  1. For beacons: the set of octets comprising the beacon payload to be transferred from the MAC sublayer entity to the next higher layer.
  2. For enhanced beacons: the set of octets containing all received IEs: first come header IEs - with the total size of total_hie_size then come payload IEs - with the total size of total_pie_size
