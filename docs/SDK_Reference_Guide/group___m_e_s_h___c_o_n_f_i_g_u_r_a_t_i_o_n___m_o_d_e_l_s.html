◆ meshCfgMdlEventValues

enum meshCfgMdlEventValues

Enumeration of the configuration model events triggered by the configuration model API. The list is shared by both the Configuration Client and the Configuration Server.

Remarks
Each event in the list is notified at the end of the corresponding operation of the Configuration Client.
The Configuration Server can optionally notify events that modify states. This means that "get" and "list" events are never notified by a Configuration Server.
