◆ ble_cmd_scan_enable()

ble_err_t ble_cmd_scan_enable ( void  )

Set BLE start Scanning.

Note
When using the SCAN function for multi-link, ensure that the current connection interval is greater than 10ms x number of links.
BLE Event
Wait for BLECMD_EVENT_SCAN_COMPLETE event which indicates the scan has been started.
Wait for BLECMD_EVENT_SCAN_REPORT event to receive scanned devices information.
Returns
BLE_ERR_OK is success or an error.
